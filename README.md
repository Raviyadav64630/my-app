# React Project

## Project Setup

This project is built using React and requires Node.js and Yarn for package management.

### Prerequisites

Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (Recommended: LTS version)
- [Yarn](https://yarnpkg.com/) (Package Manager)

### Installation

#### Step 1: Install Node.js and Yarn
1. Download and install Node.js from [here](https://nodejs.org/).
2. Install Yarn globally using npm:

   npm install -g yarn

   Verify installation with:

   yarn -v

#### Step 2: Set Up the Project
1. Clone the repository by using below command in terminal:
  
   git clone https://github.com/Raviyadav64630/my-app.git
   cd <my-app>

2. Install dependencies by using below command in terminal:

   yarn install

#### Step 3: Install Additional Packages
1. Install `react-select` for dropdown components:
   yarn add react-select

2. Install `react-bootstrap` and `bootstrap` for UI components:
   yarn add react-bootstrap bootstrap

#### Step 4: Run the Project
Start the development server:

   yarn start

The application should now be running at `http://localhost:3000/`.
